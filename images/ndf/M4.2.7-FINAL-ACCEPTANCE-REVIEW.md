## 1. Purpose and acceptance boundary

This review maps the twelve M4.2.7 milestone criteria (CAND-01 through CAND-12) to implementation evidence and records the remaining local and external gaps.

Three evidence classes must remain distinct:

1. **Unit/local contract evidence:** repository tests, deterministic fixtures and script-level validation.
2. **Workflow composition evidence:** static checks of the GitHub Actions dependency graph, inputs/outputs, permissions and stage contracts. This does not execute the workflow.
3. **Operational evidence:** a real GitHub Actions run using the DT Master-produced OCI artifact and the configured DT Master GitHub App actor. This remains externally blocked and deferred.

A green unit suite or static workflow check must not be described as a real image/PDD publication or cross-repository integration run.
