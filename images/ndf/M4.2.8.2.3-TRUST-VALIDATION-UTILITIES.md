# M4.2.8.2.3 — Artifact Trust Validation Utilities

**Status:** Implemented; local test execution pending  
**Branch:** `feat/M4.2.8`

## Scope

The reusable Python module `images/ndf/scripts/artifact_trust.py` provides deterministic validation for NDF trust metadata:

- Strict JSON loading with duplicate-key and non-finite-number rejection.
- Identity policy loading and Draft 2020-12 schema validation.
- Duplicate/ambiguous identity-purpose detection.
- Exact issuer, repository, ref, event, caller workflow and certificate identity checks.
- Exact reusable-workflow ref validation and called-workflow SHA format/pin checks.
- SLSA provenance Statement schema validation and exact image subject digest comparison.
- PDD binding Statement schema validation and exact PDD subject, image digest and descriptor content-hash comparison.
- Validation of normalized trust verification-result documents.
- A policy-validation CLI entry point.

## Security boundary

These utilities validate structured data and claims supplied by a separate trusted verification stage. They do **not**:

- Verify Cosign cryptographic signatures.
- Validate Fulcio certificate chains.
- Verify Rekor inclusion proofs.
- Authenticate the origin of OIDC/certificate claims.
- Mark an artifact trusted merely because JSON/schema validation passed.

The returned signer-claim report explicitly sets `cryptographic_signature_verified=false` and `transparency_log_verified=false`. A caller must not convert these local validation results into a trusted decision without the independent Cosign/Sigstore verification gates.

## Reusable workflow SHA

The identity policy pins the expected reusable workflow path/ref. The verifier requires the observed `job_workflow_sha` to be a full Git commit identifier and can additionally compare it with an explicitly supplied expected SHA. The expected SHA must come from trusted workflow/run configuration or captured runtime evidence, not from an untrusted attestation claim.

## Tests

`images/ndf/tests/test_artifact_trust.py` covers:

- Valid policy loading.
- Duplicate JSON key rejection.
- Positive and negative exact signer claim checks.
- Missing claim rejection.
- Reusable workflow ref and SHA matching.
- SLSA image provenance subject digest binding.
- PDD subject/image/content-hash binding.

Run:

```bash
pytest -q images/ndf/tests/test_artifact_trust.py
```

Full NDF regression and pre-commit verification remain required before acceptance.
