## 6. Scope and non-claims

- PDD v1 describes only evidence-backed product/image facts.
- Undeclared service topology, storage, networking, health/readiness, operations, infrastructure and configuration are not fabricated.
- DT Master must block deployment if its policy requires facts that remain undeclared or insufficiently verified.
- The publication locator tag is discovery-only; the OCI digest reference is authoritative.
- This package does not implement DT Master retrieval integration, candidate-driven CI/CD (M4.2.7), signing/attestation (M4.2.8), M4.2.9 integration documentation/testing, or runtime orchestration (M4.3).
